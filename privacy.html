سياسة الخصوصية — تطبيق مصاريف البيت

آخر تحديث: 2026

1. المبدأ الأساسي: الخصوصية المطلقة

تطبيق مصاريف البيت (Home Expenses) مصمم ليعمل كأداة مالية شخصية وعائلية مستقلة تماماً بدون خوادم، بدون حسابات مستخدمين، وبدون أي نوع من أنواع التتبع أو الإعلانات أو التحليلات.

2. تخزين البيانات والعمل دون إنترنت

كافة البيانات التي تقوم بإدخالها (المصاريف، الفواتير، أسماء وتصنيفات السلع، الميزانيات، والعملات):

  • تُخزّن محلياً فقط وبشكل كامل على ذاكرة جهاز الآيفون الخاص بك عبر (Apple UserDefaults / Preferences).
  • لا يتم إرسالها إلى أي خادم خارجي أو مزود سحابي، ولا يمكن لأي طرف ثالث أو حتى لمطور التطبيق الوصول إليها.
  • التطبيق يعمل بنسبة 100% دون الحاجة إلى أي اتصال بشبكة الإنترنت.

3. القياسات الحيوية وسلسلة المفاتيح (Face ID / Apple Keychain)

عند تفعيل رمز الدخول أو بصمة الوجه (Face ID / Touch ID):

  • تتم مصادقة بصمة الوجه كلياً عبر نظام iOS المدمج (LocalAuthentication Framework). التطبيق لا يستلم ولا يخزن أي صورة أو بيانات بيومترية.
  • رمز الدخول يتم حفظه كقيمة مجزأة ومملحة (Salted SHA-256 Hash) داخل سلسلة مفاتيح أبل الآمنة (iOS Keychain Services عبر SecureStorage)، ولا يُحفظ كنص عادي نهائياً.
  • عداد المحاولات الفاشلة وفترات القفل التدريجي تُدار أيضاً داخل سلسلة المفاتيح الآمنة لمنع التخمين العشوائي.

4. الإشعارات والتنبيهات المحلية

تنبيهات الفواتير والتذكير اليومي تتم جدولتها محلياً على جهازك بواسطة تقويم النظام (Apple Local Notifications)، دون أي اتصال بخوادم Push Notifications خارجية.

5. تصدير ومشاركة البيانات

أنت وحدك المالك الوحيد لبياناتك. يتيح لك التطبيق تصدير بياناتك كملف JSON للنسخ الاحتياطي أو ملف CSV لجداول البيانات، ويتم نقلها مباشرة عبر قائمة المشاركة الرسمية بنظام iOS (Share Sheet) وفق اختيارك فقط.

6. الدعم الفني والتواصل مع المطور

Privacy Policy — Home Expenses

Last updated: 2026

1. Core Principle: Zero Data Collection

Home Expenses is built as a private, offline-first personal household finance and budget tracker. There are no user accounts, no backend servers, no analytics SDKs, no tracking pixels, and no third-party advertisements.

2. On-Device Local Storage

All data you enter into the application (expenses, bills, categories, budget limits, grocery lists, and preferences):

  • Stays exclusively on your iOS device via Apple UserDefaults / Capacitor Preferences storage.
  • Is never uploaded to any remote server or third-party cloud. The developer has zero access to your financial records.
  • Functions 100% offline without requiring cellular data or Wi-Fi.

3. Biometrics & Keychain Security (Face ID / Apple Keychain)

When you enable passcode or biometric protection:

  • Face ID / Touch ID authentication is handled directly by Apple's secure iOS LocalAuthentication framework. The app never accesses or stores your biometric data.
  • Passcodes are protected using cryptographic salted SHA-256 hashes stored directly in the hardware-backed iOS Keychain (Apple Keychain Services via SecureStorage). Raw PINs are never stored.
  • Failed attempt counters and escalating lockout timers are secured within Keychain to prevent brute-force attacks.

4. Local On-Device Notifications

Bill alerts and daily reminders are scheduled purely on-device via Apple's native Local Notification API. No remote notification server is used.

5. Data Export & Ownership

You have full ownership of your data. You can back up or export your data at any time via CSV or JSON using the native Apple Share Sheet.
